# Домашнее задание к работе 2

## Условие задачи

В течение месяца продавец доставлял на дом 4 л. молока в день. 
В марте молоко стоило **x** руб. за литр. С первого апреля цена молока увеличилась на **(x + a)** руб. за литр. 
Сколько надо заплатить продавцу за все доставленное молоко в конце апреля? Количество покупаемого молока осталось прежним.

**Вариант 2**

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Объявить константы:
   - `DAILY_VOLUME` = 4 (л/день) — ежедневный объем покупки.
   - `DAYS_IN_MARCH` = 31 — количество дней в марте.
   - `DAYS_IN_APRIL` = 30 — количество дней в апреле.
3. Задать исходные данные:
   - `x` — цена 1 литра молока в марте (руб.).
   - `a` — величина, на которую базовая цена увеличивается в апреле (руб.).
4. Вычислить стоимость молока в марте:
   - `price_march` = `x`
   - `total_march` = `DAILY_VOLUME` * `DAYS_IN_MARCH` * `price_march`
5. Вычислить новую цену молока в апреле:
   - `price_april` = `x` + (`x` + `a`)
6. Вычислить стоимость молока в апреле:
   - `total_april` = `DAILY_VOLUME` * `DAYS_IN_APRIL` * `price_april`
7. Вычислить общую сумму к оплате:
   - `total_to_pay` = `total_march` + `total_april`
8. Вывести результаты расчетов с подстановкой всех значений в текст.
9. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_ALL, "Russian");

    /* 1. Константы */
    const int DAILY_VOLUME = 4;    /* ежедневный объём, л/день */
    const int DAYS_IN_MARCH = 31;  /* дней в марте */
    const int DAYS_IN_APRIL = 30;  /* дней в апреле */

    /* 2. Исходные данные */
    double x = 50.0;  /* цена 1 л молока в марте, руб. */
    double a = 5.0;   /* величина a, руб. */

    /* 3. Расчёт за март */
    double price_march = x;
    double total_march = DAILY_VOLUME * DAYS_IN_MARCH * price_march;

    /* 4. Расчёт за апрель */
    double price_april = x + (x + a);
    double total_april = DAILY_VOLUME * DAYS_IN_APRIL * price_april;

    /* 5. Общая сумма к оплате */
    double total_to_pay = total_march + total_april;

    /* 6. Форматированный вывод */
    printf("В течение месяца продавец доставлял на дом %d л молока в день.\n", DAILY_VOLUME);
    printf("В марте молоко стоило %.2f руб. за литр.\n", x);
    printf("С первого апреля цена молока увеличилась на %.2f руб. за литр.\n", x + a);
    printf("\n");
    printf("Стоимость молока в марте: %d * %d * %.2f = %.2f руб.\n",
           DAILY_VOLUME, DAYS_IN_MARCH, price_march, total_march);
    printf("Новая цена молока в апреле: %.2f + %.2f = %.2f руб. за литр.\n",
           x, x + a, price_april);
    printf("Стоимость молока в апреле: %d * %d * %.2f = %.2f руб.\n",
           DAILY_VOLUME, DAYS_IN_APRIL, price_april, total_april);
    printf("\n");
    printf("Всего надо заплатить продавцу в конце апреля: %.2f руб.\n", total_to_pay);

    getchar();
    return 0;
}
```

## 3. Результаты работы программы

```
В течение месяца продавец доставлял на дом 4 л молока в день.
В марте молоко стоило 50.00 руб. за литр.
С первого апреля цена молока увеличилась на 55.00 руб. за литр.

Стоимость молока в марте: 4 * 31 * 50.00 = 6200.00 руб.
Новая цена молока в апреле: 50.00 + 55.00 = 105.00 руб. за литр.
Стоимость молока в апреле: 4 * 30 * 105.00 = 12600.00 руб.

Всего надо заплатить продавцу в конце апреля: 18800.00 руб.
```
